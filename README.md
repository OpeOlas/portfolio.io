# Opeyemi Olaosebikan portfolio

Data governance, data management, data quality and applied data science.

## Run locally

Run `python3 -m http.server 8000` from this directory, then visit http://localhost:8000.

## Structure

`index.html`: homepage. `case-studies/`: six detailed cases. `assets/css/portfolio.css`: responsive styles. `assets/js/portfolio.js`: progressive mobile navigation. `docs/PORTFOLIO_ARCHITECTURE.md`: architecture, evidence policy and maintenance notes.

The site is static and compatible with GitHub Pages at https://opeolas.github.io/portfolio.io/. No package installation or build is required.
